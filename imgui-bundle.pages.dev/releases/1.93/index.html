Dear ImGui Bundle 1.93

Python and C++ GUIs for real-time tools and playful sketches. The same code runs on the desktop, in the browser and on phones, with no server. This release renews the explorer and the playground, which now work as well on phones and tablets, and adds an API reference with live demos. It also brings Dear ImGui 1.93: 911 commits since 1.92.900.

What's new in one minute: the explorer, the API tab, RichMd, the node editor, phones.

The highlights

Each one links to a live demo: it runs in your browser, with its code beside it.

01

A renewed explorer and playground

One welcome screen: a carousel of eleven live slides, from plots and a GPU shader to a neural network and a node editor.

Then a gallery of the demos, by category, with a search box. Each demo shows its code and runs in place. Light and dark, on a desktop or on a phone.

Run Python in your browser Explore 65 demos
02

Phones and tablets, with nothing to write

Hello ImGui turns a finger into what its user expects: a swipe scrolls with inertia, a tap clicks, a long press is a right click, two fingers pinch to scale, and a text field opens the keyboard.

Every demo of the explorer and the playground was checked on a phone.

Every gesture, in a demo
Picture: Dear ImGui 1.93.0's release notes.
03

Dear ImGui 1.93: crisper drawing

The draw list is reworked: widgets look the same or crisper, with new stroke flags for custom drawing. A drag or a slider edit can be cancelled with a right click or Escape.

Custom drawing can move by half a pixel: the changelog says how to migrate.

Dear ImGui 1.93.0 The breaking changes
04

An API reference, with live demos

The book's API pages cover all the bundle's libraries, in Python and C++. 450 entries of Dear ImGui, ImPlot and ImPlot3D show the demo that uses them: its picture, its code, and a link to run it.

In the ImGui Explorer, click an identifier in the code: its card shows its signatures, its doc, and the demo lines that use it.

The API reference The ImGui Explorer
05

RichMd: rich text you can select and search, with math

The markdown renderer is now a standalone library, imgui_rich_md, which works with a stock Dear ImGui.

Documents with a table of contents and a search, selectable text, LaTeX math, Mermaid diagrams drawn natively, and widgets inside the text.

Run a document imgui_rich_md
06

The node editor on thedmd's v0.9.4

About 110 fixes, and a test suite. Popups, combos and color pickers work inside nodes, and every editor follows the theme, light or dark.

Two new demos, in Python and C++: a color mixer and an image pipeline.

Run the image pipeline
07

Two new apps in the playground

The rotor run-up monitor: a vibration-analysis dashboard. Toggle a bearing defect, and watch it in the spectrum. Health and wealth: the nations from 1800 to 2100, after Hans Rosling's Gapminder, with the data fetched live.

Both were written with the bundle's guide for AI assistants.
